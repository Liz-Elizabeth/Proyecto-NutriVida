3. REACT - ÁTOMO Boton.jsx
Ruta: src/components/atomos/Boton.jsx
============================================================

/*
  Átomo reutilizable para enlaces que se ven como botones.
  Recibe datos mediante props.
*/
function Boton({ texto, enlace, clase }) {
  return (
    <a href={enlace} className={clase}>
      {texto}
    </a>
  )
}

export default Boton

CAMBIOS RESPECTO AL HTML:
- Antes cada <a> repetía su propia estructura.
- Ahora Boton recibe tres props: texto, enlace y clase.
- {texto} muestra el texto recibido.
- href={enlace} establece su destino.
- className={clase} aplica la clase CSS original.
- «export default» deja el componente disponible para importar.
- Este Boton está destinado a enlaces de navegación; para guardar
  formularios o ejecutar acciones se utiliza <button>.

10. GLOSARIO DE CAMBIOS IMPORTANTES
============================================================

HTML: class="hero"
JSX:  className="hero"
POR QUÉ: JSX utiliza className para clases CSS.

HTML: <!-- Comentario -->
JSX:  {/* Comentario */}
POR QUÉ: distinta sintaxis para comentarios dentro de JSX.

HTML: <img src="assets/img/habitos-saludables.png">
JSX:  import imagenHabitos from '../../assets/img/habitos-saludables.png'
      <img src={imagenHabitos} alt="Hábitos de alimentación saludable" />
POR QUÉ: Vite procesa la imagen importada como parte del proyecto.

HTML: dos <a> escritos directamente
JSX:  dos instancias de <Boton /> con props
POR QUÉ: reutilizar el átomo de navegación con apariencia de botón.

React: export default Hero
SIGNIFICA: pone Hero a disposición de otros archivos.
NO significa que se muestre automáticamente.

React: import Hero from '../components/organismos/Hero.jsx'
SIGNIFICA: Inicio.jsx obtiene el componente Hero.

React: <Hero />
SIGNIFICA: coloca lo que devuelve Hero en ese lugar de la interfaz.

React: props
SIGNIFICA: datos que el padre entrega al componente hijo.

React: Fragment <> </>
SIGNIFICA: agrupa varios elementos JSX sin crear una etiqueta HTML.

Vite: npm.cmd run dev
SIGNIFICA: inicia el servidor de desarrollo, no crea componentes.
